<h2 align="center">🚀 Projetos</h2>

<p align="center">
  <a href="https://github.com/skethron/VigiAuto"><strong>VigiAuto</strong></a>
  <br>
  Aplicativo Android para leitura automática de placas de veículos diretamente no aparelho, sem depender de
  APIs externas. Desenvolvido em Kotlin com Jetpack Compose, usa modelos ONNX (YOLOv9 + OCR) para detectar
  a placa na imagem, confirma a leitura em vários quadros e guarda o histórico com foto, data, hora e
  localização em um banco SQLite local.
  <br>
  <sub>Kotlin · Jetpack Compose · ONNX Runtime · SQLite · Visão Computacional</sub>
  <br><br>
  <a href="https://github.com/skethron/MonteAro"><strong>MonteAro</strong></a>
  <br>
  Loja virtual fictícia de pneus, aros e acessórios automotivos, com 24 páginas HTML, feito com HTML5
  semântico, CSS3 (Flexbox e Grid) e JavaScript puro, sem frameworks e sem backend. Tem catálogos,
  páginas de produto com ficha técnica, área de perfil, login, suporte e carrinho com os itens salvos no
  navegador via <code>localStorage</code>.
  <br>
  <sub>HTML5 · CSS3 · JavaScript · localStorage · Layout responsivo</sub>
